找不到 API Token？

环境变量部署：群晖 Container Manager → 本应用 API 容器 → 详情 → 环境变量 → API_TOKEN；也可查看部署目录的 .env。网页配置部署：查看映射目录中的 config.json 的 API_TOKEN。非部署者请联系管理员。GPG_KEY 是基础镜像的公钥指纹，无需填写。

01 / 连接凭据

API Token

首次生成的令牌属于管理员账户，并保留原有库存。以后在管理台创建普通账户；各账户的设备使用自己的密钥同步。

由 API_TOKEN 环境变量控制。要更改它，请在容器配置中修改并重新创建容器。

02 / 可选功能

Web 管理台

首次配置页无需安装额外镜像。完整库存管理台是独立 Web 镜像，通常使用 8081 端口。

每行一个浏览器管理台的地址（协议、主机、端口），不填 API 的 8787 地址，也不带页面路径。仅使用原生客户端时可保持默认。

由 ADMIN_WEB_ORIGINS 环境变量控制。

可留空；单独部署管理台时填写浏览器实际访问的完整 URL，反向代理的子路径也可保留。此地址用于首次配置完成后的跳转。

由 ADMIN_WEB_URL 环境变量控制。

由 WEB_INVENTORY_ENABLED 环境变量控制。
