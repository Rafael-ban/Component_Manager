# 0.7.7-dev.5：旧库存参数批量补全

服务端和 Web 新增“补全旧元件参数”维护工具。按当前账户既有 LCSC SKU 预览缺少参数的元件，确认后逐项查询官方描述与电气参数，再通过正常同步传回 Android 和 Windows。名称、库存、库位、最低库存与流水不变。

支持进度、取消、失败及未处理项重试、活动任务恢复、完成记录清除。查询在事务外进行，写入前检查元件是否被同时修改；只有官方明确的数据才保存。默认无 OpenAPI 配置也能查公开商品页，不改变全局自动识别 fallback 开关。

使用前同步各设备并保留备份；成功后再次同步获取资料。已有参数行的记录不自动覆盖，服务重启后重新预览剩余候选。详见[操作与部署指南](../parameter-enrichment.md)。

- Web 测试 23 项及构建通过；包括任务恢复、重试条件和已知失败原因显示。

- Android 沿用 dev.4 已实机检查的四按钮布局，本轮没有修改打印或原生库存事务。
