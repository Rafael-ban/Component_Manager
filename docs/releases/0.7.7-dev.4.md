# 0.7.7-dev.4：左滑直达四项操作

按用户提供的效果图，库存卡片左滑后直接横排显示入库、出库、转移、删除四个按钮，移除 dev.3 的中间“操作”菜单。

- 点击入库或出库，直接在列表上填写数量与库位。
- 点击转移，打开该 SKU 的库位与数量弹窗；库存总量不变。
- 点击删除，仍需确认后执行。
- 每个按钮保持至少 48 dp 宽；右滑或点击卡片收起，多选时不展开。

沿用 dev.3 的元件参数与搜索实现，不改业务事务、数据格式或打印协议。本版本仍为开发预发布。

## 实机验证

已在连接手机覆盖安装 `0.7.7-dev.4 (707004)`。实际左滑显示四个横排按钮；逐个打开入库、出库、转移、删除确认并取消，返回库存列表。出库正确显示所选库位可用 10；仅有一个库位时转移明确提示需要另一个启用库位。未提交库存操作，主页核对仍为 26 项元件、810 个库存、26 条记录。

本轮对原有 C22036 的只读核对确认：旧记录只保存了型号、品牌和链接，没有官方参数资料；客户端升级不会凭空补全这类数据。后续服务端维护工具负责批量重新查询。手机测试结束后恢复原 60 秒息屏设置。测试未打印，也未删除或新增真实库存。
