# 0.7.7-dev.3：元件参数与库存快捷操作

Android 库存卡片左滑展开“操作”，点击后显示该元件的名称、SKU，以及入库、出库、转移和删除。
菜单与表单均覆盖在当前列表上，不进入元件详情或独立变动页面。

## 使用方式

- 入库：选择目标库位，填写增加数量并提交。
- 出库：选择有库存的库位，填写减少数量；不能超过该库位当前可用数量。
- 转移：选择来源与目标库位、数量，复核后提交；库存总量不变。
- 删除：打开原有删除确认框，取消不会改变库存。

关闭菜单或取消表单后回到原列表。提交期间禁用重复操作，失败保留输入和错误提示。
批量选择模式继续使用原有批量转移，不启用左滑快捷操作。

本轮复用已有入出库和转移事务、流水与同步队列，不增加数据库表或改变库存同步格式；查询响应另行增加参数字段。
该版本仍为开发预发布；不更新 Docker 稳定镜像，也不扩展 Windows 的快捷菜单。

## 元件参数

新导入默认名称保持品牌和型号，阻值、容量、电感量、耐压、精度、功率等参数在基本信息中单独显示并参与检索。Android、Windows 和 Web 兼容读取既有中英参数行；服务端查询补充传递官方描述和参数对象。不会自动批量改写既有名称，不从型号猜测缺失参数。
