# 0.7.7-dev.2：实机交互修正

本版本继续作为开发预发布，沿用 dev.1 的搜索、标签工具和 Windows 界面重整，不更新 Docker 稳定标签。

## 修正内容

- Android 库存左滑最多展开 80 dp 的删除操作区，卡片主体保持可见。右滑或点卡片收回，只有点击删除按钮才打开原有确认框；选择模式不启用滑动删除。关闭时隐藏底部删除区域，避免圆角漏出危险色。
- 库存搜索只显示当前结果数量，避免无结果时仍显示全库存分类、库位数量。
- 标签内容编辑将“完成”固定在面板顶部，输入内容可滚动；空元素显示“文字”或“二维码”，不再显示内部 ID。

## 验证范围

已在连接手机上复现 dev.1 的整卡滑走和标签输入时完成按钮受键盘遮挡问题。搜索型号片段、清空和无结果状态，以及单库位时批量转移提示已实机检查。测试未删除、转移库存或执行打印。

dev.2 的 CI 和安装后验证结果记录在 [打印功能与实测记录](../m1-printing-feature-matrix.md)。本轮不改变 M1 协议、走纸参数或渲染器；Windows 改动仍属于 dev.1，尚无本轮 Windows 界面实机验收。
