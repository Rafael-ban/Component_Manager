# 0.7.4-dev.8 — 打印预览生命周期修复

包含 dev.7 的 M1 实际标签、批量队列和 Web 配置编辑。

- 实机发现 dev.7 切换预览时偶发 `Canvas: trying to use a recycled bitmap`。
  已显示到 Compose 的位图交由平台按引用释放，避免渲染线程还在使用时被主动回收；
  未显示的临时渲染位图仍会及时释放。
- 增加纸张尺寸反复切换和预览重绘的 UI 回归测试。
- 实际标签不打印外框；保持 1 mm 纸面留白、水平/垂直整图平移和二维码静区检查。
  不修改 dev.6 验证的 M1 分帧与正常走纸命令。

dev.7 覆盖安装后原有 26 个元件、库存总量 810 保持不变，但预览闪退阻止其通过实机验收。
