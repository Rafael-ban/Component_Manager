# 0.7.4-dev.7 — Android M1 标签队列与服务端设置入口

本开发版延续 dev.6 的 M1 正常分帧和走纸方式，扩展实际库存标签与多份任务。

- 元件标签预览新增蓝牙打印，库存提供批量入口。选择元件、份数和实际纸张尺寸，
  预览同一份 203 dpi 位图，再逐张发送；不改变库存数量。
- 支持短二维码、完整二维码和文字标签，以及本地旋转和偏移。二维码使用整数点模块和
  完整静区，无法容纳时提示修改纸张或模板，不通过裁掉二维码继续打印。
- 当前队列保存到本机，支持逐张进度、暂停、停止、核对后重打或跳过及继续未发送项。
  重启后的发送中项转为待核对，部分发送和结果不明确的项不自动重打。
- 正常打印固定正常标签走纸，每张重新核对型号和状态；收到处理通知、型号正常且无
  已知错误才继续下一张。已发送不代表已验收实物；设备设置与试验走纸保留在诊断中。
- 服务端首次配置可指定 Web 管理台地址，完成后进入管理台；后续在管理台设置页
  修改服务端配置。未配置管理台地址时继续提供 `/setup`；环境变量覆盖规则保持不变。

## 验收范围

dev.6 已在 Android 15 / 该台 M1 / 40×60 mm 间隙纸上通过连续两张固定图。
本版需要进一步检查：真实元件二维码可扫描、同一元件连续多份、不同元件顺序、
暂停/继续，以及停止或退出后的核对恢复。CI、完整写入和处理通知都不替代物理出纸验收。
其他品牌、Windows 蓝牙、浓度和纸张学习等设备设置仍属后续独立适配。
