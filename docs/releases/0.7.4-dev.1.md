# 0.7.4-dev.1 — M1 单张打印与更新通道

这是 Dev 测试版，不替代 0.7.3 正式版。Android 与 Windows 的更新通道默认仍为正式版。

- Android 标签预览新增独立的“打印一张 M1 测试标签”。复用现有 40 × 10 / 40 × 30 mm
  纸张尺寸，发送固定文字、边框和测试二维码。发送前重新确认 M1 型号和状态。
- 打印采用 Classic SPP、整行 POLI/LZO 分包和一次走纸。取消、断连与超时保留诊断信息，
  不自动重发，不将“数据已发送”显示为“打印成功”。
- Android 与 Windows 在“设置 → 关于”加入正式版 / Dev 测试版更新通道选择，保存在本机。
  Dev 检查预发布与更高正式版；切回正式版不会自动降级或清除数据。
- 发布的 Dev APK 与正式 APK 使用相同应用身份及发布签名；Windows 继续提供自包含 ZIP。
  Dev 发布不更新 Docker Hub 的正式镜像标签。

## M1 测试方法

1. 关闭汉码等其他打印 App，保持 M1 已配对、装有对应尺寸间隙标签纸。
2. 在“元件详情 → 标签预览”选择 10×40 mm QR 或 30×40 mm QR。
3. 打开“蓝牙标签机诊断 → M1 测试”，扫描设备，点击“打印一张 M1 测试标签”。
4. 核对纸张尺寸后发送。应输出一张含 `M1 TEST` 的标签，二维码内容为 `M1-TEST`。
5. 反馈是否出纸、尺寸和方向、文字完整度、二维码能否识别，并附诊断报告。

实机已确认 0.7.3 的 M1 型号 / 状态查询；本版的实际出纸仍待验证。
日常元件内容打印、批量蓝牙打印和其他品牌适配尚未开放。
出现发送中断时，请先检查打印机是否已出纸，再决定是否重试。

旧版没有更新通道选项，可从本次预发布页面手动下载同签名 APK 覆盖安装，保留应用数据。
之后可在应用内选择 Dev 并检查后续版本；安装仍由用户主动完成。
