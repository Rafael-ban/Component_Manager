# 0.7.4-dev.2 — M1 查询回复与纸张适配测试

本版继续作为 Dev 预发布；正式版仍为 0.7.3。
上一版已收到 M1 实际出纸照片，但纸张适配和重复打印尚未完成验收。

- 修复 M1 型号查询中混入异步状态帧时被错误识别为型号不匹配的问题。
  保留精确型号匹配，并区分普通查询回复和异步状态，不放宽缺纸等状态限制。
- M1 测试增加本地纸张画布、旋转和位置偏移设置及预览。
  宽度指沿打印头方向，高度指走纸方向；初始尺寸来自原有 QR 模板。
  按实际纸张尺寸设置，偏移超出画布的内容仍会裁切。
- 测试开始后自动回到进度位置，失败或中断时弹窗展示诊断并提供复制按钮，
  避免按钮下方看不到状态而误认为没有响应。

这些设置只影响发送的图像，不写入打印机纸张类型、校准或永久配置。
未复制汉码代码或打包其 SDK；本次不改变已出纸的 LZO 编码及走纸指令。

## 验证步骤

1. 从“设置 → 关于”选择 Dev 通道并检查更新，安装本次 APK。
2. 关闭汉码，进入“标签预览 → 蓝牙标签机诊断 → M1 测试”。
3. 打开“纸张与位置”，填写实际标签宽高；先保持偏移为 0，再根据预览选择方向。
4. 只打印一张，确认尺寸和位置；完成后再主动打印第二张。
5. 若第二次仍不出纸，复制第二次的诊断报告，并补充重开诊断页面或重启打印机能否恢复。

异步回复混入是源码中已确认的缺陷，但在取得第二次失败报告前，
不能认定它就是所有“只能打印一次”的原因。请保留本次测试结果以继续定位。
