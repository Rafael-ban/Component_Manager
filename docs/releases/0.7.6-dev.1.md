# 0.7.6-dev.1 — 统一标签编辑与蓝牙打印

包含 0.7.5 正式版的账户隔离、Web 中英语言切换和中文部署教程。本开发版集中调整 Android 标签流程。

- 元件标签与批量标签进入同一个“标签编辑与打印”页面，移除独立的预览导出页和蓝牙诊断弹窗；高级排障保留可复制的打印报告。
- 支持修改标签显示文字，选择并拖动文字块或二维码，以及用毫米数值调整位置和尺寸。修改仅用于标签，不改变库存元件或二维码身份。
- 编辑草稿按元件分开保存，屏幕旋转保留当前草稿。队列按张保存文字与布局快照，兼容读取原有 v1 队列；打印中断仍要求核对，不自动重打不确定项。
- PNG、PDF、预览和蓝牙打印共用同一纸面渲染结果。屏幕选择框不会出现在导出文件或实际标签上。
- 修正连续拖动时重绘中断手势的情况，数值字段允许输入小数与临时空值；非法位置、文字溢出和二维码静区冲突需修正后才能打印。
- 保持 0.7.4 实测通过的 M1 图像分帧和走纸协议，不更改设备校准值。

## 验证与边界

发布前通过 GitHub CI 验证 Kotlin 构建、连续拖动与越界修复、原有预览生命周期和大队列回归、二维码解码与设计快照持久化。

新编辑器仍需在实际纸张上确认编辑后的位置和连续打印结果。历史 40×60 mm 两张正常打印记录不能替代新布局的实测。自由标签、取件码模板与正式物流面单不在这一开发版范围内。

旧正式版不能编辑 v2 自定义布局队列；需要回到旧版时先完成或清除当前打印队列，库存数据不受此操作影响。Android 系统通常不允许直接覆盖降级安装，因此日常设备建议继续使用正式通道，测试设备选择 dev 通道。
