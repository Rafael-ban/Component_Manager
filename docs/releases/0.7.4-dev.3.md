# 0.7.4-dev.3 — M1 连续测试连接与打印后诊断

Dev.2 实机报告确认：首次能出纸，后续 SPP 已连接，但型号查询没有任何回复，
且第二张图像尚未发送。改变第二张纸张尺寸不能修复这一阶段的故障。

- 测试打印采用页面内持久 SPP 连接，下一次主动点击复用；仍逐次查询型号与状态。
  停止、离开页面、错误或空闲 60 秒后释放连接，不自动重打。
- 按汉码 Classic SPP 的发送粒度，每次最多写入 1024 字节并 flush；
  图像帧内容、LZO 编码和单次走纸指令保持不变。
- 首次发送后保留一秒接收窗口，再执行只读型号查询并记录结果，
  用于区分断开前已失去响应与重新连接后的故障。
- 已发送数据后查询失败仍明确标记已发送，不误报“未发送”，也不自动补打。

上游复用连接与当前每张断开的差异已经静态确认；它是否为该台设备只能打印一次的
根因，仍需实机验收。型号回复成功也不等于机械打印完成。

## 复测

1. 安装 Dev.3。若打印机仍处于此前故障状态，先关闭再打开 M1 电源一次。
2. 关闭汉码，在蓝牙标签机诊断中选择 M1，保留已量好的纸张尺寸。
3. 打印一张，等待打印后查询结束，保存这次完整报告。
4. 留在同一页面，60 秒内直接再次点击打印，不重新扫描或读取 BLE 服务。
5. 保存第二次报告；重点保留连接是否复用、`post_print_model` 及已发送字节信息。
6. 若两次均正常，再测试离开页面后重进。这样可单独验证关闭后重新连接的行为。
