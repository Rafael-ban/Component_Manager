# 0.7.7-dev.1：库存搜索与标签编辑交互重做

这是开发预发布，用于验证 0.7.6 的界面修正；不替换正式版，不更新 Docker 稳定标签。

## 本轮范围

- Android 库存搜索改为列表内即时筛选，输入时不再用空白展开层遮住结果。保留多字段、多关键词匹配与清空查询；本轮未引入新的搜索引擎。
- 库存操作栏收紧，标签工具放入更多菜单；主动选择元件后才出现批量转移操作。左滑展示取消、删除，删除仍需确认。
- 批量转移按库位与数量组织内容，长列表可滚动，复核与提交固定可见；保留原有整批事务及库存版本校验。
- Windows 使用桌面命令栏与原生列表多选，提供明确的结果/空状态；转移表单与复核分开，数量列表可滚动。
- Android 标签界面参考已安装汉码的画布、上下文工具与固定打印入口，复用现有渲染器、队列和 M1 传输流程；模板入口、元件快捷入口继续共用编辑器。
- 发布渠道按更新日志最新具体版本标题识别：带 `-dev.N` 为预发布，无后缀为正式版；只修改 `Unreleased` 不发布。本地提交钩子只检查版本，不再自动把待发布内容转成正式版本。

## 验证重点

搜索时应立即看到命中数量和列表；键盘收起、清空和无结果都应可理解。标签编辑时画布、当前元素与主要操作应可见，内容/位置/纸张设置按需展开；队列中断恢复和删除确认不得退化。

设备、CI 与构建验证结果会记录在本项目的标签指南中。发布前不将编译通过等同于实际出纸验收。
